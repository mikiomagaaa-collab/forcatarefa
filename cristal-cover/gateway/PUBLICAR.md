# Publicar o L.I.L.Y Gateway

Editar este arquivo publica o gateway na sua conta Cloudflare (workflow "L.I.L.Y Gateway - publicar").

1. Antes, crie os segredos do repositório (veja `cristal-cover/docs/GATEWAY.md`, passo 3.5).
2. No navegador do celular, abra este arquivo no GitHub, toque no lápis (Edit), mude a linha abaixo
   (por exemplo, a data) e toque em "Commit changes".
3. Abra a aba Actions: no fim da execução aparece o endereço do seu gateway.
